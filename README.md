# Lampa Windows

**Lampa для Windows с интегрированным TorrServer GST.**

Смотрите фильмы и сериалы через встроенный плеер Lampa. Встроенная интеграция с **TorrServer GST** помогает стабильно воспроизводить торрент-потоки прямо в приложении, без лишних настроек и сторонних плееров.

## Что нового

- **TorrServer GST** — интегрированный сервер для воспроизведения торрент-потоков.
- **Встроенный плеер** — запуск контента непосредственно в Lampa.
- **Звук без проблем** — благодаря TorrServer GST решены проблемы с отсутствием звука при воспроизведении.
- **Простая настройка** — установка, запуск и обновление TorrServer GST из приложения.
- **Автоматическое подключение** — GST может запускаться вместе с приложением.
- **Windows-приложение** — Lampa в отдельном окне, без браузера.

## TorrServer GST

TorrServer GST интегрирован с Lampa и предназначен для удобного воспроизведения потоков через встроенный плеер. Сервер можно установить, обновить, запустить или остановить из настроек приложения.
